# Pregled metoda

- **Kenny Mitchell — Volumetric Light Scattering as a Post-Process**, GPU Gems 3, poglavlje 13. [Cijelo poglavlje kod NVIDIA-e](https://developer.nvidia.com/gpugems/gpugems3/part-ii-light-and-shadows/chapter-13-volumetric-light-scattering-post-process). Referenca za screen-space pristup.
- **Ray marching kroz shadow map po pikselu.** Ovo je naziv metode, a ne zasebnog rada u početnom popisu. Za poređenje s froxel pristupom vidjeti Wronskijev slajd „Why not 2D raymarching?” u [osnovnoj literaturi](../Zasto%20Froxel/README.md).
- **Markus Billeter, Erik Sintorn, Ulf Assarsson — Real Time Volumetric Shadows using Polygonal Light Volumes**, High Performance Graphics, 2010. [Zapis izdavača i DOI](https://doi.org/10.2312/EGGH/HPG10/039-045), [PDF kod Eurographics-a](https://diglib.eg.org/server/api/core/bitstreams/bce2f6b1-5dd6-428d-9975-e4aec9ad9526/content).
- **Markus Billeter, Erik Sintorn, Ulf Assarsson — Real-Time Multiple Scattering using Light Propagation Volumes**, I3D, 2012. [Stranica rada na Chalmersu](https://research.chalmers.se/publication/156140), [DOI](https://doi.org/10.1145/2159616.2159636).
