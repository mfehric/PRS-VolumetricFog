# Zašto froxel

- ★ **Bartłomiej Wronski — Volumetric Fog: Unified, Compute Shader Based Solution to Atmospheric Scattering**, SIGGRAPH, 2014. [Stranica autora](https://bartwronski.com/publications/), [PDF slajdova s bilješkama](https://bartwronski.com/wp-content/uploads/2014/08/bwronski_volumetric_fog_siggraph2014.pdf). Glavna referenca za grid poravnat s kamerom, injection, integraciju i primjenu.
- ★ **Sébastien Hillaire — Physically-based and Unified Volumetric Rendering in Frostbite**, SIGGRAPH, 2015. [Stranica autora](https://sebh.github.io/publications/), [materijali kursa](https://advances.realtimerendering.com/s2015/). Na stranici kursa izlaganje je naslovljeno „Towards Unified and Physically-Based Volumetric Lighting in Frostbite”; odatle su dostupni materijali. Stari EA link sa stranice autora vraća 404.

Oba izvora obrađuju GPU implementacije. CPU/OpenMP/SIMD verzija u ovom projektu predstavlja prilagodbu algoritma, a ne implementaciju preuzetu iz rada o CPU froxel magli.

Hillaireovi slajdovi dostupni su i preko [direktnog PPTX linka na serveru kursa](https://advances.realtimerendering.com/s2015/Frostbite%20PB%20and%20unified%20volumetrics.pptx) (oko 158 MB).
