# Paralelizacije (CPU)

- **Aaron Knoll, Sebastian Thelen, Ingo Wald, Charles D. Hansen, Hans Hagen, Michael E. Papka — Full-Resolution Interactive CPU Volume Rendering with Coherent BVH Traversal**, IEEE Transactions on Visualization and Computer Graphics, 2011. [PDF na stranici autora](https://www.sci.utah.edu/~wald/Publications/2011/OVRC/ovrc.pdf). Referenca za koherentni traversal i SIMD integraciju; nije rad o froxel magli.
- **Jason Nieh, Marc Levoy — Volume Rendering on Scalable Shared-Memory MIMD Architectures**, Workshop on Volume Visualization, 1992, str. 17–24. [Stranica rada na Stanfordu](https://graphics.stanford.edu/papers/vv92/), [DOI](https://doi.org/10.1145/147130.147141). Paralelizacija volumetrijskog renderiranja i task queue podjela posla.
- **Matt Pharr, William R. Mark — ispc: A SPMD Compiler for High-Performance CPU Programming**, InPar, 2012. [PDF na službenoj stranici projekta](https://ispc.github.io/papers/ispc_inpar_2012.pdf), [dokumentacija](https://ispc.github.io/documentation.html). Referenca za SPMD-on-SIMD model.
- **Ingo Wald, Sven Woop, Carsten Benthin, Gregory S. Johnson, Manfred Ernst — Embree: A Kernel Framework for Efficient CPU Ray Tracing**, ACM TOG, 2014. [PDF na stranici projekta](https://embree.github.io/papers/2014-Siggraph-Embree.pdf), [DOI](https://doi.org/10.1145/2601097.2601199). Referenca za CPU/SIMD kernele, ne za algoritam magle.
- **Intel — Memory Layout Transformations.** [Službeni članak](https://www.intel.com/content/www/us/en/developer/articles/technical/memory-layout-transformations.html). Referenca za AoS/SoA raspored podataka.
